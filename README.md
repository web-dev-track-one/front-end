# University of Toronto Track One Engineering Program Frontend

This repository contains the frontend code for the TrackOne Discipline Club website, a platform designed for engineering students to access important information, stay updated on upcoming events, and learn more about the club and its members.

**Features**
 - User-Friendly Interface: Intuitive and clean design to help users easily navigate the website.
 - Routing for Multiple Pages: The application includes separate pages for:
 - Upcoming Events: A list of all future club events.
 - Due Dates: Important assignment or project due dates.
 - About Us: Information about the TrackOne Discipline Club.
 - Meet the Team: Introduces the club's team members.

**Technology Stack**
 - TypeScript: For robust and type-safe code.
 - React: The main framework for building the user interface.
 - Fetch API: Used for making HTTP requests to the backend.
 - CSS: For styling the components, with emphasis on creating visually appealing designs.
 - Routing: React Router for managing navigation across different pages of the site.
